# Manganese Reserve Predictor — ML Pipeline

A standalone satellite-based ML pipeline that predicts manganese ore reserves at new lat/lon locations using Sentinel-2 imagery and a trained Random Forest classifier.

> **Isolated from the main portal** — no existing files are affected.

---

## Folder Structure

```
mn-reserve-predictor/
├── data/
│   ├── manganese_locations.csv     ← 35 known MOIL + GSI deposit lat/lons
│   ├── satellite_features.csv      ← SWIR, NDVI, LST, rainfall per location
│   └── final_dataset.csv           ← generated by Step 1 (positive + negative)
├── models/
│   ├── mn_classifier.pkl           ← trained Random Forest model
│   └── label_encoder.pkl           ← rock type encoder
├── outputs/
│   ├── evaluation_report.png       ← confusion matrix + ROC + feature importance
│   └── prediction_*.png            ← per-location prediction overlay images
├── sentinel_images/                ← downloaded .tif files per location
├── 01_prepare_dataset.py           ← merge + negative sampling + labels
├── 02_download_sentinel.py         ← Copernicus API downloader (UNCHANGED)
├── 03_train_classifier.py          ← Random Forest training + evaluation
├── 04_predict_new_location.py      ← inference for any new lat/lon
└── requirements.txt
```

## Step-by-Step Running Instructions

### Step 1 — Prepare the Labeled Dataset
```bash
python 01_prepare_dataset.py
```
**What it does:**
- Merges `manganese_locations.csv` + `satellite_features.csv` on `mine_id`
- Generates 70 negative samples (barren/non-Mn regions)
- Adds `has_manganese` column (1 = deposit, 0 = barren)
- Saves `data/final_dataset.csv`

**Output:** `data/final_dataset.csv` (105 total rows: 35 positive + 70 negative)

---

### Step 2 — Download Sentinel-2 Image (Optional — requires Copernicus credentials)
```bash
python 02_download_sentinel.py
```
**What it does:**
- Authenticates with Copernicus Dataspace API
- Downloads a 5km × 5km Sentinel-2 (L2A) GeoTIFF for test_001
- Displays True Colour RGB image
- Saves to `sentinel_images/test_001/sentinel2.tif`

> You will be prompted to enter your Copernicus Client ID and Client Secret.

---

### Step 3 — Train the Manganese Classifier
```bash
python 03_train_classifier.py
```
**What it does:**
- Loads `data/final_dataset.csv`
- Trains a Random Forest (200 trees, balanced class weights)
- 5-fold cross-validation ROC-AUC evaluation
- Saves evaluation plots to `outputs/evaluation_report.png`
- Saves model to `models/mn_classifier.pkl`

**Expected output:**
```
5-Fold CV ROC-AUC: 0.91 ± 0.04
ROC-AUC Score    : 0.93
```

---

### Step 4 — Predict Manganese at a New Location
```bash
python 04_predict_new_location.py
```
**What it does:**
1. Asks for Copernicus credentials
2. Asks for a new **latitude** and **longitude**
3. Downloads the Sentinel-2 image for that location
4. Extracts SWIR B11/B12, NDVI, LST from the image
5. Asks for rainfall, soil moisture, magnetic anomaly, elevation, rock type
6. Predicts: `X% manganese probability` + `LIKELY / UNLIKELY`
7. Displays: Sentinel-2 image with Mn-signature overlay + prediction panel
8. Saves output to `outputs/prediction_*.png`

**Example interaction:**
```
Enter Latitude  (e.g. 21.8167): 21.65
Enter Longitude (e.g. 80.1833): 80.02
...
PREDICTION RESULT
Location   : (21.65, 80.02)
Probability: 87.4% manganese
Decision   : 🟢 MANGANESE LIKELY
```

## Key Scientific Basis for Features

| Feature | Why it matters |
|---|---|
| **SWIR B11/B12** | Manganese oxides show diagnostic absorption at 1610–2190 nm |
| **NDVI** | Geochemical halos from Mn toxicity suppress vegetation |
| **LST** | Bare exposed ore-bearing ground = higher thermal signature |
| **Magnetic Anomaly** | Braunite & Jacobsite (Mn spinels) are ferrimagnetic |
| **Rock type** | Gondite/Braunite Series of Sausar Group = primary MOIL host rock |
